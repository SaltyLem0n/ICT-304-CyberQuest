A. Key Vocabulary & Meanings (Term → Plain Meaning → Purpose / Distinction)

PKI (Public Key Infrastructure): Binds public keys to identities using CA-signed certs. Validate trust, identity, expiry & revocation (CRL/OCSP).

CA (Certificate Authority): Signs X.509 certs; verify with its public key (not decrypted).

KDC (Key Distribution Center): Issues session keys/tickets; needed during issuance (Kerberos port 88).

Digital Sig: Hash H(M) signed w/ sender PRA → Auth + Integrity + Non-Repud (not secrecy).

Hash: One-way fixed digest; 1-bit flip changes ~50% bits (avalanche) → integrity check, not encryption.

ACL (Access Control List): Ordered top-down filter; first match wins, implicit deny any → std = source IP only.

Wildcard Mask: 0 = must match, 1 = ignore → /24→0.0.0.255, /27→0.0.0.31 (inverse of subnet mask).

VLAN (Virtual LAN): Logical L2 broadcast domain (usually maps 1:1 to an IPv4 subnet; L3 routing needed between VLANs).

Trunk & Native VLAN: 802.1Q link carrying multiple tagged VLANs; Native VLAN is untagged and must match both ends.

SVI (Switch Virtual Interface): Virtual L3 interface for a VLAN; gives an L2 switch a management IP.

VTY (Virtual Teletype): Remote-login lines; apply login, transport and access-class to every supported line.

SSH (Secure Shell): Encrypted remote CLI with host authentication. Lab: RSA host keys + local login.

HA vs FT: HA (High Availability) minimizes downtime via redundancy/failover. FT (Fault Tolerance) keeps service running through specified failures.

MitM (Man-in-the-Middle): Intercepts/alters traffic or keys; authenticate peers to mitigate.

B1. Ch 5 · RSA Calculations & Symbols

Symbols: p,q=distinct primes; n=p·q (modulus); φ(n)=(p−1)(q−1) (totient, keygen only); e=public exp; d=private exp; m=plaintext (0≤m<n); c=ciphertext.

1. n = p·q, z = φ(n) = (p−1)(q−1)
2. Pick e: 1<e<z, gcd(e,z)=1 → Public PU=(n,e)
3. Find d: e·d ≡ 1 (mod z) → Private PR=(n,d)
4. Enc: c = me mod n | Dec: m = cd mod n

Textbook vs Modern: Textbook RSA swaps PU/PR only for raw (me)d≡(md)e; real RSA uses OAEP (enc) / PSS (sig) + hybrid session key K.

Conf: Enc PUB, dec PRB. Auth/Int: Sign PRA, verify PUA.

Find Private Key d & How to Do mod (Calculator)

Find d: Test k=1,2,3… in d = (1 + k·z) ÷ e until a whole number (check e·d mod z = 1). mod: A mod B = remainder = A − ⌊A÷B⌋×B.

Repeated Squaring (Square & Multiply)

Split exp into powers of 2 (173=128+32+8+4+1). Square & reduce mod n each step; multiply chosen powers mod n.

Checked Mini RSA Example

Keygen: p=3, q=11 → n=33, z=2×10=20. e=3 (gcd(3,20)=1).
Find d: k=1 → (1+20)÷3 = 21÷3 = 7 (3×7=21≡1 mod 20) ✓
Enc m=4: c = 43 mod 33 = 64 mod 33 = 31.
Dec c=31 (d=7=4+2+1): 311≡31; 312≡4; 314≡16 (mod 33) → m=(31×4×16) mod 33 = 4 ✓
Fast (p=3,q=5; A=1,B=2…): n=15, z=8, e=3⇒d=3. B(2): 23=8; 83=512≡2 (mod 15) ✓

Mistakes: Use φ(n) ONLY for d; use n for enc/dec! Keep m<n; never pack a whole name > n.

B2. Ch 6 · Signatures & Hashing

E-Sig ≠ Digital Sig: Digital sig = Authentic, Unforgeable, Non-Reusable, Unalterable, Non-Repudiable.

Envelope: EK(M) || EPU_B(K) || EPR_A(H(M)) (Conf+Int+Auth).

B4. Ch 8 · TLS 1.3, PGP & IPsec

Layers: App: HTTPS(443), SSH, PGP | Transp: TLS | Net: IPsec | Link: PPTP/L2TP.

TLS 1.3 (RFC 8446): 5 AEAD suites; (EC)DHE gives forward secrecy (PSK-only psk_ke & 0-RTT have exceptions; no static RSA kex, RC4, 3DES, CBC, SSL/TLS≤1.1).

PGP (Pretty Good Privacy): Hybrid + sig via Key Ring & Web of Trust (no CA).

IPsec (L3, IKE key exchange): AH (Authentication Header) = auth+int only, no enc; ESP (Encapsulating Security Payload) = configurable encryption/integrity; normally both.
