Ch 5 · Public Key Cryptography & RSA

1. Pick primes p, q (p ≠ q) → n = p·q, z = φ(n) = (p−1)(q−1)
2. Choose e: 1 < e < z, gcd(e, z) = 1 → Public Key PU = (n, e)
3. Find d: e·d ≡ 1 (mod z) → Private Key PR = (n, d)
4. Enc (0 ≤ m < n): c = me mod n | Dec: m = cd mod n

Trapdoor: Multiplication easy, factoring n hard. Textbook RSA keys are interchangeable only for raw (me)d ≡ (md)e (mod n) (not general ECC/OAEP/PSS).

  • Confidentiality: Encrypt with PUB, decrypt with PRB.
  • Auth / Integrity: Sign with PRA, verify with PUA.
  • Hybrid: Random symmetric session key K encrypts data (fast); PUB encrypts K. Still needs PKI/CA against MitM.

Modular Inverse (Extended Euclidean: z & e)

Write z = 1·z + 0·e, e = 0·z + 1·e. At each division ri−1 = q·ri + ri+1, subtract q × (row i) from (row i−1). When remainder = 1, coeff of e mod z is d (if negative, add z).

Repeated Squaring (Square & Multiply)

Split exponent into powers of 2 (e.g. 173 = 128+32+8+4+1). Square & reduce mod n each step; multiply selected powers mod n.

Checked Mini RSA Example

Keygen: p=3, q=11 → n=33, z=2×10=20. Pick e=3 (gcd(3,20)=1).
Inv: 20=6×3+2 (2=1·20−6·3); 3=1×2+1 (1=−1·20+7·3) → d=7 (3×7=21≡1 mod 20).
Enc m=4: c = 43 mod 33 = 64 mod 33 = 31.
Dec c=31 (d=7=4+2+1): 311≡31; 312=961≡4; 314≡42=16 (mod 33).
m = (31×4×16) mod 33 = 1984 mod 33 = 4 (60×33=1980, rem 4) ✓

Pitfalls: Use z ONLY to find d; use n for all enc/dec! Keep m < n; never concatenate a whole name into one block > n.

Ch 6 · Digital Signatures & Hash Functions

E-Sig ≠ Digital Sig: Digital sig = cryptographic hash H(M) signed with PRA. Properties: Authentic, Unforgeable, Non-Reusable, Unalterable, Non-Repudiable. Provides Auth + Integrity + Non-Repudiation (not confidentiality).

Digital Envelope: EK(M) || EPU_B(K) || EPR_A(H(M)) → Confidentiality + Integrity + Auth.

HashBits/HexStatus & Key Fact
MD5128b / 32Broken (2004 Wang & Yu collision). Avoid.
SHA-1160b / 40Deprecated (2017 SHAttered collision).
SHA-256256b / 64Recommended (TLS, certs, FIM, HMAC).
SHA-3224–512bSponge design; resists length-extension.

Avalanche: 1-bit input flip (bat→cat) changes ~50% output bits. Hashing is one-way compression, NOT encryption.

X.509 Cert: (1) Subject Public Key, (2) Subject ID + Validity, (3) CA Signature. Cert is plaintext signed by CA (verified with CA's PU, not decrypted). Win tool: certmgr.msc.

Base64 Encoding (RFC 4648)

Maps 3 bytes (24b) → four 6-bit chars: 0–25=A–Z, 26–51=a–z, 52–61=0–9, 62=+, 63=/. Pad: 2B left → =; 1B left → ==.

Ex: Man→TWFu, an→YW4=, G→Rw==. certutil -encode adds BEGIN/END CERTIFICATE lines; PS [Convert]::ToBase64String(...) does not.

Ch 8 · TLS 1.3, PGP, VPN & IPsec

Layers: App: HTTPS (443), SSH, PGP, S/MIME | Transp: SSL/TLS | Net: IPsec | Link: PPTP, L2TP.

TLS 1.3 (RFC 8446): SSL 2/3 & TLS 1.0/1.1 deprecated. TLS 1.3 allows only 5 AEAD suites (e.g. TLS_AES_128_GCM_SHA256) + mandatory Forward Secrecy (removed static RSA key exchange, RC4, 3DES, CBC).

PGP: Hybrid + signature using Key Ring & decentralized Web of Trust (no CA).

IPsec (Layer 3): AH (auth+int, NO enc) vs ESP (enc+auth+int). Key setup: IKE.

Ch 10 · Resiliency & Site Security

Availability = (Total − Downtime) / Total. 99%=3.65d/yr | 99.9%=8.76h/yr | 99.99%=52.6m/yr | 99.999%=5.26m/yr.

HA vs FT: HA = standby failover (sec–min downtime, lower cost); FT = active-active real-time mirror (0 downtime, $$$).

RAID: RAID 0 = striping, min 2 disks, 0 fault tolerance. RAID 1 = mirroring, 50% cap, tolerates 1 disk failure (not a backup!). Multi-switch paths need STP.

3-2-1-1-0: 3 copies, 2 media, 1 offsite, +1 immutable/air-gapped, 0 errors. Don't mix Inc & Diff.

Sites: Hot (instant, $$$) | Warm (hours–days, manual cfg, $$) | Cold (empty, days–wks, $).

Physical (5 Ds): Deter, Detect, Deny, Delay, Defend. Guard=Preventive; CCTV=Detective. Mantrap stops tailgating. PDS=sealed metal conduit. Faraday/TEMPEST=blocks EM leaks.
