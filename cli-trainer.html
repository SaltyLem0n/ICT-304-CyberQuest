5-Step Memory Routine (How to Practise)

  1. Follow once: type worked example & explain each command
  2. Recall: hide commands & reconstruct from requirements
  3. Apply: repeat with coherent new addresses/ports/policies
  4. Troubleshoot: find faults using simulated show output
  5. Record mistakes: symptom → cause → verify cmd → fix
